# Pergadaian Utama Indonesia (PUI)

Website resmi **Pergadaian Utama Indonesia** — platform gadai aset mewah seperti tas branded, jam tangan mewah, dan perhiasan berlian dengan proses cepat, aman, dan transparan.

## 🛠 Stack

- **React 19** + **TypeScript**
- **Vite 8** (build tool)
- **TailwindCSS v4** (styling)
- **React Router v7** (routing)
- **GSAP** + **AOS** (animasi)
- **Leaflet** (peta interaktif)
- **FontAwesome / Lucide / React Icons** (ikon)
- **react-helmet-async** (SEO per halaman)

## 🚀 Memulai

```bash
pnpm install
pnpm dev
```

Build production:

```bash
pnpm build
```

Preview build:

```bash
pnpm preview
```

## 📁 Struktur

| Path               | Keterangan                        |
| ------------------ | --------------------------------- |
| `src/components/`  | Komponen UI                       |
| `src/data/`        | Data statis & tracking            |
| `src/services/`    | Service layer                     |
| `src/utils/`       | Utility functions                 |
| `src/css/`         | Stylesheet                        |
| `public/assets/`   | Gambar & aset statis              |
